# 🌸 Iris Flower Detective

A Streamlit app that uses a Random Forest classifier to predict Iris flower species from sepal and petal measurements.

## Features
- Predict Setosa, Versicolor, or Virginica.
- View prediction probabilities and model performance.
- Explore the dataset and feature importance.

## Technologies
Python, Streamlit, Pandas, Scikit-learn, and Matplotlib.

## Run the App
Place `iris.csv` in the same folder as `app.py`, then run:

pip install streamlit pandas scikit-learn matplotlib
streamlit run app.py
